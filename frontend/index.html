learning diary

this application is built using a multi-tier containerized architecture deployed on the CSC Rahti platform

frontend uses nginx web server which is serving static HTML and client-side javascript, listening on port 8080 and proxying API traffic

backend uses express.js REST API running on port 5000 with endpoints /api/data and /api/visit

database uses MySQL relational database running on port 3306 storing visit records in the visits table

all source code changes are tracked in github. rahti uses buildconfig resources connected to the repository. triggering manual builds in the rahti web console automatically takes the latest code, builds updated docker images, and re-rolls the pods.

the internal communication between pods uses mainly kubernetes clusterip services;

backend-service > routes internal traffic to port 5000

mysql-service > routes internal traffic to port 3306

nginx > takes incoming browser traffic to port 8080 and proxies backend API requests internally
